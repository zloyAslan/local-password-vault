# 🔐 local-password-vault

**local-password-vault** — це безпечний консольний менеджер паролів, написаний на **Python 3.14**. Він дозволяє надійно зберігати, генерувати та керувати вашими обліковими даними прямо в терміналі за допомогою шифрування. Усі дані зберігаються тільки локально.

## ✨ Можливості (Функціонал)
Програма має простий та інтуїтивний текстовий інтерфейс українською мовою, де керування відбувається за допомогою вибору пунктів меню:
1. **Генерація надійного пароля** — створення випадкового пароля із заданою довжиною та використанням різних елементів (літери, цифри, символи).
2. **Додавання власного пароля** — збереження нового сервісу/логіну із шифруванням «на льоту».
3. **Перегляд (розшифрування)** — безпечне відображення збережених даних (завдяки `pyperclip` пароль можна зручно копіювати).
4. **Видалення пароля** — очищення непотрібних записів із бази.
5. **Зміна майстер-пароля** — оновлення головного ключа доступу до вашого сховища.

*Додатково*: Завдяки модулю `difflib` додаток підтримує розумний пошук і вміє розпізнавати правильні назви, навіть якщо ви зробили друкарську помилку!

## 🛡 Безпека та технології
* **Шифрування**: Використовується алгоритм **AES-128** у режимі CBC (через симетричний метод `Fernet` бібліотеки `cryptography`).
* **Хешування**: Майстер-пароль захищено за допомогою безпечних хеш-функцій модуля `hashlib`.
* **Прихованій ввід**: Введення паролів у консолі повністю маскується завдяки `getpass`.

## 🚀 Як запустити локально

### 📋 Вимоги
Вам знадобиться встановлений **Python 3.14+**.

### 🔧 Встановлення та налаштування
1. Клонуйте цей репозиторій:
   ```bash
   git clone https://github.com
   cd local-password-vault
   ```
2. Встановіть необхідні зовнішні залежності:
   ```bash
   pip install cryptography pyperclip
   ```

### 💻 Запуск програми
Запустіть менеджер паролів командою в терміналі:
```bash
python main.py
```
## 🔒 Безпека (Security Notice)
Цей проект створено з метою безпечного локального зберігання даних. Проте, автор не несе відповідальності за втрату даних у разі забуття мастер-пароля. Завжди робіть резервні копії зашифрованої бази даних.
